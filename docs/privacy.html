3
収集

本アプリが収集する個人情報

  • ありません。本アプリは利用状況・統計・クラッシュレポートを収集しません
  • アカウント登録、ログイン、メールアドレス等の入力を求めることはありません
  • 広告および行動解析のためのコードを含みません
  • 開発者が、利用者の設定内容・デスクトップの状態・操作履歴を受け取ることはありません

本サイトについて

  • 本サイトは静的ページのみで構成され、Cookie を設定せず、アクセス解析を行いません
  • 本サイトは GitHub Pages 上で公開されているため、閲覧時に GitHub 社が IP アドレス等のアクセス情報を取得・記録します。詳細は GitHub プライバシーステートメント をご確認ください
4
端末内の処理

端末内でのみ読み取る情報

以下は表示のために読み取りますが、いずれも利用者の PC 内で処理され、外部へ送信されません。

  • デスクトップアイコンの名称と位置 (配置の保存・復元のため)
  • CPU・メモリ・ディスク・ネットワークの状態 (ハードウェアモニタ等のため)
  • 再生中のメディア情報 (曲名・アーティスト名・アルバムアート。再生中ウィジェットのため)
  • システム音声 (ビジュアライザーの表示のため。解析のみを行い、録音・保存はしません)
  • 利用者が指定したファイル・ショートカットのパスとアイコン画像 (フォルダウィジェットのため)

保存場所と保持期間

  • 設定は %APPDATA%\AeroWidget\config.json に保存されます
  • 追加したフォント、オンライン壁紙の画像も同フォルダ内に保存されます
  • バージョン更新時、同フォルダ内に設定のバックアップを最大 5 世代保持します
  • 保持期間の上限は設けていません。利用者が削除するまで端末内に残ります
5
外部通信

接続先と、送信される情報

いずれの通信も、対応するウィジェットを配置するか、該当する設定を有効にした場合にのみ発生します。 通信を行う以上、接続先には IP アドレスおよび接続日時が必ず伝わります。 以下はそれに加えて送信される情報です。

  • GitHub (更新の確認・ダウンロード、リリース情報の取得) — 現在のバージョン番号。 プライバシーステートメント
  • Open-Meteo (天気・週間予報・地名検索) — 利用者が指定した地点の緯度経度、または検索した地名。 Terms & Privacy
  • Google Fonts (フォントの追加) — 利用者が指定したフォント名。 Privacy & Data Collection
  • Yahoo Finance (株価ウィジェット) — 利用者が指定した銘柄コード。 Privacy Policy
  • Bing 画像 / Picsum (オンライン壁紙) — なし (画像の取得のみ)。 Microsoft ・ Picsum
  • RSS 配信元 (ニュースウィジェット) — なし (指定した URL の取得のみ)。 初期値として NHK ニュースの RSS が設定されているため、URL を変更しない場合は NHK へ 30 分ごとに接続します。 URL は設定画面で自由に変更・削除できます
  • 利用者が指定したカレンダー (ICS) 配信元 (予定表ウィジェット) — なし (同上)
  • 利用者が登録したリンク先 (フォルダウィジェットのアイコン取得) — なし。 当該サイトの favicon を直接取得します。第三者のアイコン取得サービスは経由しません
  • ローカルネットワーク上の LibreHardwareMonitor (詳細な温度表示。既定では無効) — 利用者が指定したアドレスへの接続のみ。インターネットには出ません

配置していないウィジェットに関する通信は発生しません。すべてのウィジェットを削除すれば、 更新の確認を除き外部通信は行われません。更新の確認も設定で無効にできます。
