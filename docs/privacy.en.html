Privacy Policy

Privacy Policy

This policy describes how personal data is handled by the AeroWidget desktop application and by this website (orahu01.github.io/aerowidget). 日本語版

Effective: 22 August 2026 ・ Last updated: 22 August 2026

1
Controller

Who is responsible

  • Orahu01, an individual developer (GitHub: @Orahu01)
  • AeroWidget is developed and distributed by an individual, not a company
  • Privacy enquiries: GitHub Issues
2
Scope

What this covers

  • The AeroWidget desktop application for Windows (“the app”)
  • The website at https://orahu01.github.io/aerowidget/ (“the site”)

External services the app can connect to (section 5) are governed by their own operators' policies. This policy does not cover how those services handle data.

3
Collection

Personal data collected by the app

  • None. The app collects no telemetry, usage statistics or crash reports
  • There is no account, no sign-in, and no request for an email address or any other identifier
  • The app contains no advertising and no behavioural analytics code
  • The developer never receives your settings, your desktop contents or your activity

The website

  • The site consists of static pages only. It sets no cookies and runs no analytics
  • The site is hosted on GitHub Pages, so GitHub receives and logs access information such as your IP address when you visit. See the GitHub Privacy Statement
4
On your device

Information read locally

The app reads the following in order to display widgets. All of it is processed on your own PC and none of it is transmitted.

  • Desktop icon names and positions (to save and restore arrangements)
  • CPU, memory, disk and network status (for the hardware monitor and related widgets)
  • Currently playing media information — title, artist, album art (for the now-playing widget)
  • System audio (for the visualizer; it is analysed in real time, never recorded or stored)
  • Paths and icons of files and shortcuts you add (for the folder widget)

Storage and retention

  • Settings are stored at %APPDATA%\AeroWidget\config.json
  • Downloaded fonts and online wallpaper images are stored in the same folder
  • On a version change, up to five generations of settings backups are kept in that folder
  • There is no retention limit: data remains on your device until you delete it
5
Network

Where the app connects, and what is sent

Each connection happens only if you place the corresponding widget or enable the corresponding setting. As with any internet request, the destination necessarily receives your IP address and the time of the request. Listed below is what is sent in addition to that.

  • GitHub (update checks, downloads, release notes) — the version you are running. Privacy Statement
  • Open-Meteo (weather, forecast, place-name lookup) — the coordinates you chose, or the place name you searched for. Terms & Privacy
  • Google Fonts (adding a font) — the font family name you chose. Privacy & Data Collection
  • Yahoo Finance (ticker widget) — the symbols you entered. Privacy Policy
  • Bing image of the day / Picsum (online wallpaper) — nothing beyond the request itself. Microsoft ・ Picsum
  • RSS feeds (news widget) — nothing beyond fetching the URL. Note that the widget ships with NHK News as its default feed, so unless you change the URL it will contact NHK every 30 minutes. The URL can be changed or the widget removed at any time
  • Calendar (ICS) URLs you configure (agenda widget) — same as above
  • Websites you add as links (folder widget icons) — nothing beyond fetching that site's own favicon. No third-party icon service is used
  • LibreHardwareMonitor on your local network (detailed temperatures; disabled by default) — a connection to the address you configure. This does not leave your network

Widgets you have not placed generate no traffic. With no widgets configured, the app makes no network requests other than update checks, and update checking can be turned off in settings.

6
Disclosure

No sharing or selling

  • The developer does not share or sell user data to third parties — no such data is collected
  • Connections to the services in section 5 occur only as needed to provide the feature you enabled
7
Your rights

Your data stays with you

  • The developer holds no stored user data that could be subject to an access, correction or erasure request
  • Access and export: use “Backup” in the settings window, or read %APPDATA%\AeroWidget\config.json directly
  • Erasure: uninstall the app and delete that folder. The uninstaller lets you choose whether to keep or remove your settings
8
Other

Children

  • The app is suitable for users of any age. Because no personal data is collected, no age-based distinction applies

Changes to this policy

  • If this policy changes, this page is updated and the “last updated” date is revised
  • Every revision is visible in the commit history

Verification

  • The complete source code is published on GitHub under the MIT license, so every statement in this policy can be checked against it
  • Released binaries are built by GitHub Actions from that public source
