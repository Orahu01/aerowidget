Changelog

ここまでの道のり。

各版の配布物と詳細は GitHub の Releases にあります。 番号の付け方は、頭の数字が大きな節目 (v5 → v6)、 マイナーが奇数なら新機能の先行版 (5.3 / 5.5)、偶数なら安定版 (5.2 / 6.0)、 3 つめが残っていた不具合の修正 (5.2.1) です。先行版は設定で受け取りを ON にした方にだけ届きます。

5.9.2
先行版・修正

隠したアイコンが元の位置に戻るようになりました

  • 「元の位置に戻す」を押すと、隠す前にあった場所へ戻ります。以前は空いている場所へ並べ直すだけでした
  • 隠す直前の位置をアプリが覚えているので、保存した配置が無くても戻せます。元の位置が今の画面に無いものだけ、空いている場所へ並べます

アップデートの案内

  • 更新すると何が変わるのかを、設定画面に表示するようにしました。これまではバージョン番号しか出ておらず、更新するか判断できませんでした
  • リリースの説明文を日本語で書くようにしました (英語のコミット題名が並ぶだけでは伝わらないため)
  • 公開直後で準備が整っていないときのエラーを、「少し待ってからもう一度」と分かる言い方に変えました
5.9.1
先行版・修正

設定画面をページごとに分けました

  • 「一般」に 13 個の節が詰まっていたのを整理し、アイコンとシーンを独立したページにしました
  • 壁紙スケジュールは壁紙タブへ、レイアウトプリセットはシーンへ (同じ話題なので)。「設定」には言語・ホットキー・起動と電力・フォント・バックアップ・アップデートだけが残ります

隠したアイコンを全部呼び戻すボタン

  • アイコンのページの一番上に「すべて表示する」を置きました。隠したアイコンが分からなくなっても、これを押せば全部画面に戻ります
  • 保存した配置が無くても戻せます。画面の外にいるアイコンを探して、空いている場所へ並べ直す作りです
5.9.0
先行版

アイコンをシーンで出し分ける

  • ゲームを起動するとゲーム用のアイコンだけになり、閉じると元に戻る——という切り替えができるようになりました。壁紙・ウィジェットの配置・デスクトップアイコンが、ひとつのルールで同時に切り替わります
  • 隠す仕組みは画面のすき間 (どのモニタにも映らない領域) への退避です。ファイルもレジストリも触らないので、アイコンが消えたり壊れたりすることはありません
  • 隠したいアイコンは設定画面でクリックして選ぶだけ。配置に名前を付けて保存し、シーンのルールから指定します
  • モニタが画面いっぱいですき間が無い環境では隠せません。その場合は設定画面がそう伝え、フォルダウィジェットで必要なものだけ並べる方法を案内します

切り替えボタン (新ウィジェット・全 27 種に)

  • デスクトップに置いたボタンでレイアウトを手動で切り替えられます。いま当たっている構成のボタンが光るので、どのモードにいるか一目で分かります

使い勝手

  • アイコン配置の一覧から「復元前 (自動)」を分離しました。安全網であって選ぶものではないので、一覧の下に「元に戻す」として控えめに置いています

これは先行版です。設定 → 一般 →「先行版を受け取る」を ON にした方にだけ届きます。

5.7.0
先行版

デスクトップアイコンの配置を保存 / 復元

  • アイコンの並びを名前つきで保存しておき、解像度の変更やモニタの抜き差しで散らかったときに元へ戻せます。DesktopOK のような機能を本体に内蔵しました
  • 保存は読み取るだけ。配置を書き換えるのは「復元」を押したときだけです。復元の直前には今の並びを「復元前 (自動)」として退避するので、戻しすぎても元に戻せます
  • 復元は名前で照合し、一致しないアイコンには一切触れません (推測で動かさない)
  • 「解像度が変わったら自動で戻す」も選べますが既定はオフのオプトイン。ふつうに使う限り、ボタンを押さなければ 1 バイトも書き込みません

これは先行版です。設定 → 一般 →「先行版を受け取る」を ON にした方にだけ届きます。

5.5.0
先行版

シーン — 状況でレイアウトが切り替わる

  • ゲームが前面のときはゲーム用、仕事の時間帯は仕事用——のように、レイアウトプリセットを状況で自動的に切り替えます
  • きっかけは 4 種類: アプリが前面 / フルスクリーン中 / 時間帯 (曜日つき) / バッテリー駆動中。ルールは上から順に評価され、最初に当てはまったものが勝ちます
  • シーンはレイアウトを「指す」だけで、構成そのものは持ちません。切り替えの直前、未保存の配置は「シーン切替前 (自動)」レイアウトに退避されるので、作業が消えることはありません
  • 「前面のアプリを取得」ボタンで、exe 名を調べなくても対象アプリをクリックするだけで登録できます
  • レイアウト編集中はシーンを止めます。編集を終えた直後に勝手に切り替えることもしません

バグ修正

  • 設定ファイルに無い項目の既定値が読み込み時に失われることがある問題を修正 (更新で追加された新しい設定が効かなくなる時限バグでした)

これは先行版です。設定 → 一般 →「先行版を受け取る」を ON にした方にだけ届きます。

5.4.0
安定版

WidgetWall から AeroWidget へ改名

  • 同名のアプリが Mac App Store に存在していたため、名前を変えました
  • 設定は自動で引き継がれます。初回起動時に旧フォルダから設定・フォント・オンライン壁紙を取り込みます (旧フォルダは残るので、手で戻すこともできます)
  • アイコンを一新 — 三角の A と逆三角の W を並べた、翼にも読めるモノグラム
  • 更新すると別アプリとして入るため、旧「WidgetWall」は「アプリと機能」から手動でアンインストールしてください
5.3.0
先行版

呼び出せるダッシュボード

  • ホットキー (既定 Ctrl+Alt+A) を押すと、いまの配置がそのまま最前面に浮かび上がります。作業中でウィンドウに壁紙が隠れていても、ひと目で確認できます
  • もう一度押すか Esc、または余白のクリックで閉じます
  • カーソルのあるモニタにだけ出す / すべてのモニタに出す を選べます。背景の暗さも調整できます
  • 背後の画面を取り込むのではなく壁紙をそのまま描くので、動作が軽く、表示中もウィジェットは生きたまま更新され続けます

ホットキー

  • 他のアプリと衝突して登録できなかったキーを、設定画面で赤く示すようにしました。これまでは黙って効かないだけで、理由が分かりませんでした

これは先行版です。設定 → 一般 →「先行版を受け取る」を ON にした方にだけ届きます。

5.2.0
安定版

自動バックアップ

  • アプリのバージョンが変わると、設定を自動で退避します (直近 5 世代)。更新のあとだけでなく、前の版に戻したときも守られます
  • 設定 → 一般 → バックアップ から、日時を選んで復元できます。復元の前にも今の設定を退避するので、行き来できます

先行版

  • 「先行版を受け取る」を ON にすると、新機能を試せる開発版 (5.3 / 5.5 のようにマイナーが奇数の版) が届きます
  • 先行版は確認なしにインストールされません。OFF のままなら安定版だけが届きます

バグ修正

  • 設定のインポートが必ず失敗していた問題を修正 (内部関数が公開されておらず、「読み込みに失敗」となっていました)
  • インポート時のバックアップが際限なく溜まり続けていたのを、直近 5 世代までに整理するようにしました
