Changelog

ここまでの道のり。

各版の配布物と詳細は GitHub の Releases にあります。 番号の付け方は、v5 のような整数が機能追加、v4.2 が小さな追加と修正、v4.2.1 が残っていた不具合の修正です。

5.0.0
最新

テーマとセットアップ

  • デスクテーマ集 6 種をワンクリック適用 (ミニマル / サイバー / 和 / 情報ダッシュボード / フォーカス / ミュージック)
  • 初回起動ウィザード — テーマを選ぶだけで完成した状態から始められます
  • 設定画面のライブプレビュー — いじった結果がその場で確認できます

新ウィジェット 8 種 (全 26 種に)

  • 天気予報 (時間別 / 週間)、予定表 (ICS 購読・Google カレンダー対応)、世界時計、ToDo リスト
  • バッテリー、ディスク空き容量、ネットワーク情報 (IP / SSID / 遅延グラフ)、ビジュアライザー

壁紙

  • フォルダ指定のスライドショー + シャッフル
  • オンライン壁紙 (Bing の日替わり / ランダム写真)
  • マウス視差効果

操作性

  • グローバルホットキー (ウィジェット表示 / アイコン表示 / レイアウト切替 / ポモドーロ)
  • 編集モード強化 — 複数選択・整列・等間隔、矢印キー微調整、Ctrl+Z 取り消し、Ctrl+D 複製、右クリックでロック
  • デスクトップアイコンの表示設定を「一般」タブとトレイへ移動。編集バーのボタンは配置作業中だけの一時切替になりました

その他

  • 英語 UI に対応 (システム言語から自動判定 / 手動切替も可)
  • winget への登録を申請、実機スクリーンショットを紹介ページに掲載
4.2.1
修正

バグ修正

  • 「A JavaScript error occurred in the main process」で起動できない問題を修正。音量・再生中の曲で使う PowerShell スクリプトが配布アーカイブ内に固められており、実行できずにエラーになっていました
  • あわせて、インストール版で「再生中の曲」が表示されなかった問題も解消 (同じ原因でした)
  • ヘルパーの停止時にアプリごと落ちないよう、エラー処理を強化
4.2.0
追加と修正

新機能

  • 音量・出力切替ウィジェット — デスクトップ上でスライダー / ホイールから音量調整、ミュート、再生先の切り替え
  • 再生中の曲に再生操作を追加 — 再生 / 一時停止・前へ・次へ
  • 編集モードでデスクトップアイコンの表示を切り替えられるように

バグ修正

  • メモ・タイマーの枠をドラッグするとレイアウトが崩れる問題を修正 (サイズ変更は設定のスライダーか編集モードのホイールから)
  • 設定画面のウィジェット項目が右端で見切れる問題を修正
  • 設定画面のロゴをアプリアイコンに変更
4.1.0
修正

バグ修正

  • メモ・ポモドーロタイマー・フォルダがクリックできない問題を修正。デスクトップに貼り付ける際、ウィンドウを Progman の子にしていたためマウス・キーボード入力が一切届いていませんでした。トップレベルのまま Z オーダーだけデスクトップ直上に差し込む方式へ変更しています
  • メモに文字を入力できるようになりました (自動保存も動作)
  • 対話ウィジェットのサイズが、解像度・拡大率の違うモニタでばらつく問題を修正
  • フォルダから一部のアプリ (電卓など) が起動しなかった問題を修正
4.0.0
機能追加

新ウィジェット 6 種 (全 17 種に)

  • 再生中の曲 (SMTC 連携)、ニュース (RSS)、株価・為替、カウントダウン、メモ、ポモドーロタイマー

壁紙

  • スライドショー (クロスフェード切替)、アルバムアート壁紙、明るさスライダー、曜日ごとのスケジュール

ハードウェアモニタ

  • 推移グラフ (スパークライン)、温度アラート (しきい値超えで赤表示)

使い勝手・信頼性

  • 自動アップデート、レイアウトプリセット、設定の書き出し / 読み込み、修復・アンインストールボタン
  • フォルダウィジェットのサイズ不安定を修正、混在 DPI での設定ウィンドウの位置ずれを修正
3.0.0
機能追加
  • 設定画面を全面リニューアル — チャコール + ゴールドのフラットデザイン、ストローク SVG アイコン
  • 新ウィジェット: アナログ時計、カレンダー、画像
  • 壁紙スケジュール (昼 / 夜の自動切替)
  • カスタムグラデーションが最大 10 色に対応
  • フォルダウィジェットが .lnk / .url に対応 (リンク先のアイコンを解決)
  • デジタル時計・ハードウェアモニタ表示のガタつきを修正、フォントピッカーを検索式に変更
2.0.0
機能追加

  • 省電力設計の全面見直し — アイドル時 GPU 使用率 0%、フルスクリーン検知による自動停止
  • 新ウィジェット: ハードウェアモニタ、ゾーン、ライン、フォルダ
  • Google Fonts のワンクリック追加に対応
