01Concept

壁紙は、いちばん長く見ている画面。

デスクトップは一日に何十回も目に入るのに、たいていはただの背景です。 AeroWidget は、そこへ知りたいことを置いておくためのアプリ。 いま何時か、外は暑いか、CPU は熱くないか、次の予定は何時か—— ウィンドウを開かずに済むことが増えるほど、作業は途切れません。

ウィジェットはアイコンの背面に描かれます。だからアイコンもファイルもそのまま使えるし、 壁紙を右クリックする感覚も変わりません。必要なときだけ、メモやタイマーは前面で反応します。

02Widgets

26 種のウィジェットを、1px 単位で。

時計だけでも 3 種類。天気、週間予報、購読カレンダーの予定表、世界時計、 ハードウェアモニタ、ディスク残量、ニュース、株価、付箋、ToDo、ポモドーロ、 音量つまみ、再生中の曲、音に反応するビジュアライザー。 フォント・サイズ・色・影・不透明度は、すべて個別に決められます。

ドラッグで、置くだけ

「レイアウトを編集」を押せば、デスクトップ上でそのまま移動。ホイールで拡大縮小、矢印キーで 1px ずつ、複数選択して整列も。

モニタごとに別の顔

解像度も拡大率も違う複数のモニタで、それぞれに壁紙と配置を持てます。混在 DPI でもズレません。

触れるウィジェット

付箋には直接書き込め、タイマーは押せて、音量つまみは動きます。フォルダにアプリをまとめれば、スマホのホーム画面のように。

03Themes

迷ったら、できあがったものから。

6 つのテーマを同梱しています。初回起動で選ぶだけで配置と配色が完成し、 そこから好きに崩していけます。適用前の構成は自動で保存されるので、いつでも戻せます。

04Performance

常駐するものは、軽くなければ。

止まっている絵に GPU を使わない設計です。アイドル時の GPU 使用率は 0%。 秒針や数字が変わる瞬間だけ描き直し、更新のいらないウィジェットはタイマーすら持ちません。

ゲームや動画をフルスクリーンにすると、描画は自動的に止まります。 壁紙のために fps を 1 でも失うのは、本末転倒なので。

GPU 0% / IDLE

静止中は再描画しません。動画壁紙を選んだときだけ動きます。

CPU 約 3% / 1 CORE

実測値。時計を含むひと通りのウィジェットを表示した状態で。

フルスクリーン検知

ゲーム中・動画再生中は自動で停止し、戻ると再開します。

まずは、時計をひとつ置いてみる。

インストールした瞬間から壁紙は表示されます。あとは好きなものを足していくだけ。
