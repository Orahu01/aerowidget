できること

ウィジェット 17 種

時計 (デジタル/アナログ)・日付・カレンダー・カウントダウン・天気・ニュース RSS・株価・再生中の曲・メモ・ポモドーロ・ハードウェアモニタなど。

どこでも、好きな見た目で

デスクトップ上を直接ドラッグして配置。フォント・サイズ・色・影を自由に。Google Fonts もフォント名を入れるだけで使えます。

PC の状態がひと目でわかる

Libre Hardware Monitor 連携で CPU / GPU の温度・使用率、SSD、ネット速度を表示。推移グラフと温度アラート付き。

壁紙も自由自在

画像・動画・スライドショー・グラデーション・再生中の曲のジャケット。昼と夜、曜日ごとの自動切替にも対応。

アイコン整理もおまかせ

色分けゾーンでデスクトップを仕分け。フォルダウィジェットにアプリをまとめれば、スマホのホーム画面のように使えます。

軽い。とにかく軽い

アイドル時 GPU 0%。ゲームなどフルスクリーン中は描画を自動停止。実測 CPU 約 3% (1 コア比) の省電力設計です。

はじめかた

1

WidgetWall-Setup.exe をダウンロードして実行。ワンクリックでインストールされ、すぐに壁紙が表示されます。SmartScreen が出たら「詳細情報」→「実行」。

2

壁紙とウィジェットを選ぶ。設定画面から好きな壁紙にして、ウィジェットを追加。

3

「レイアウトを編集」でドラッグ配置。ホイールでサイズを変えて、保存して完了。あとはトレイに常駐して、サインイン時に自動で復元されます。
