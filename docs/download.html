01Install

インストーラ版 — おすすめ

自動起動と自動アップデートが有効になります。管理者権限は不要で、ユーザーごとにインストールされます。

AeroWidget-Setup-x.y.z.exe をダウンロードして実行します。ワンクリックでインストールが完了し、そのまま起動します。

「Windows によって PC が保護されました」と出たら。署名証明書のない個人開発アプリのため表示されます。「詳細情報」→「実行」で進めます。中身が気になる方はソースコードをどうぞ。

初回ウィザードでテーマを選びます。これで壁紙とウィジェットの配置が完成します。あとから設定画面でいくらでも変更できます。

設定画面はトレイアイコンから。タスクバー右下の常駐アイコンをクリックすると開きます。

02Portable

ポータブル版

インストールせず、exe をダブルクリックするだけで動きます。USB メモリに入れて持ち歩いたり、 会社の PC で試したりする場合に。自動アップデートは効かないので、更新は手動でファイルを差し替えてください。

03Command line

コマンドラインから

winget への登録を申請中です。公式リポジトリに取り込まれると、次のコマンドで導入できるようになります。

winget install Orahu01.AeroWidget

それまでは、上記のインストーラ版をお使いください。 審査の状況は winget-pkgs のプルリクエストで確認できます。

ソースからビルドする

Node.js 18 以降が必要です。

git clone https://github.com/Orahu01/aerowidget.git
cd aerowidget
npm install
npm start        # 開発起動
npm run dist     # インストーラ / ポータブル版を生成
04Notes

知っておくと困らないこと

更新のしかたインストーラ版なら、新しい版が出たときに設定画面で通知されます。「更新を確認」からその場で適用でき、再起動すると新しい版になります。
PC の温度を表示するにはハードウェアモニタの温度表示には Libre Hardware Monitor が必要です。管理者として起動し、設定で「Remote Web Server」を有効にしてください。使用率とメモリだけなら、なくても表示されます。
設定の保存場所%APPDATA%\aerowidget\config.json です。設定画面の「書き出し」から、この構成をファイルにまとめて別の PC へ持っていけます。
調子が悪いとき設定画面の「一般」タブに修復ボタンがあります。壁紙が消えた、ウィジェットが出てこないといったときは、まずこれを押してください。
アンインストールWindows の「アプリと機能」から、または設定画面の「一般」タブのアンインストールボタンから。デスクトップアイコンを隠していた場合も、終了時に必ず元へ戻ります。
うまくいかない・要望があるGitHub の Issues へどうぞ。日本語で構いません。よくある質問は Wiki の FAQ にまとめています。
