# WidgetWall

デスクトップアイコンの**背面**に表示される、ウィジェット付きライブ壁紙アプリ (Windows 10 / 11)。
Wallpaper Engine と同じ WorkerW 方式で、時計・日付・天気・ハードウェアモニタなどを
好きなフォント・サイズ・色・位置で壁紙に直接描画します。

## 機能 (v2)

### 壁紙
- グラデーションプリセット 6 種
- **カスタム壁紙ビルダー** — 好きな色を組み合わせてグラデーション/単色を自作、パレットに保存
- 画像 (jpg, png, gif, webp) / 動画 (mp4, webm) — 動画は GPU ハードウェアデコード
- **透過モード「今の壁紙のまま」** — Windows の壁紙はそのままにウィジェットだけ追加
- 暗さ・ぼかし調整、任意で transform ベースの軽量アニメーション
- **マルチモニタ対応** — モニタごとに別の壁紙を設定可能

### ウィジェット (モニタごとに配置可能)
- 🕐 時計 / 📅 日付 (和欧 6 形式) / ⛅ 天気 (Open-Meteo、API キー不要)
- ✏️ テキスト
- 📊 **ハードウェアモニタ** — [Libre Hardware Monitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 連携で
  CPU/GPU 温度・使用率、メモリ、SSD 温度、ネット速度 (LHM の Options → Remote Web Server → Run を有効化)
- 🔲 **ゾーン** — 色分け枠 + ラベルでデスクトップのアイコンを「ゲーム」「仕事」のように仕分け
- 📏 **ライン** — 区切り線 (縦横・破線・太さ)
- 📁 **フォルダ** — スマホのようにアプリをまとめる小型ランチャー。アイコン群の上・全アプリの下に常駐し、クリックで起動

### カスタマイズ
- 「レイアウトを編集」でデスクトップ上を直接ドラッグ、ホイールでサイズ、ゾーンはハンドルでリサイズ
- フォントは検索できるスクロール式ピッカー (システム全フォント)
- **Google Fonts をフォント名だけで追加** (ダウンロードしてオフライン使用、日本語フォント対応)
- 太さ / 色 / 不透明度 / 字間 / 影 (ソフト・ネオン発光)

### 省電力設計 (v2 の最重要ポイント)
- 背景は既定で完全静止 — **アイドル時 GPU 使用率 0%**
- 時計は秒表示なしなら**毎分しか起きない**タイマー設計
- **フルスクリーンアプリ検知** (WinEvent フック駆動・ポーリングなし) — ゲーム中はそのモニタの描画を自動停止
- メインプロセスの定期処理は単一ハートビートに集約 (複数 setInterval による CPU 空回りを排除)
- 実測: アプリ全体で 1 コアの約 3% (秒表示時計あり) / GPU 0%

### その他
- 自動起動 (サインイン時に壁紙だけ静かに復元)
- トレイ常駐、explorer.exe 再起動から自動復旧、レンダラ死活監視
- インストーラは最大圧縮 + 不要ロケール除去で軽量化

## 使い方

1. `WidgetWall-Setup-*.exe` (インストーラ) か `WidgetWall-Portable-*.exe` (単体 exe) を実行
2. 設定画面で壁紙とウィジェットを設定
3. 「🎯 レイアウトを編集」→ デスクトップ上でドラッグ → 保存して完了
4. ✕ で閉じてもトレイに常駐して壁紙は表示され続けます
5. 「一般 → Windows 起動時に自動で開始」を ON で次回から自動表示

## 開発

```bash
npm install
npm start          # 開発起動
npm run genicon    # アイコン再生成
npm run dist       # exe ビルド (dist/)
```

## 仕組み

`Progman` に `0x052C` を送って WorkerW を生成させ、Electron のウィンドウを `WS_CHILD` 化して
アイコンレイヤー (`SHELLDLL_DefView`) の背面にある WorkerW へ `SetParent`。
フォルダウィジェットは逆に Progman 直下の最前面 (アイコンより上・全アプリより下) に置くことで
クリック可能にしています (Rainmeter と同じ層)。
Win10 型と Win11 24H2 型の両ウィンドウレイアウトに対応。DPI スケールが異なるモニタは
物理ピクセルで配置し `zoomFactor` で表示を補正します。

## 制限

- 透過モード「今の壁紙のまま」はスライドショーの切替に追従しません (モニタごとに別の Windows 壁紙を使っている場合は最後に設定した 1 枚になります)
- コード署名なしのため、配布した exe の初回実行時に SmartScreen 警告が出ます (「詳細情報」→「実行」)
