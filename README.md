# WidgetWall

デスクトップアイコンの**背面**に表示される、ウィジェット付きライブ壁紙アプリ (Windows 10 / 11)。
Wallpaper Engine と同じ WorkerW 方式で、時計・日付・天気などを好きなフォント・サイズ・色・位置で壁紙に直接描画します。

![screenshot](assets/icon.png)

## 機能

- **壁紙**: グラデーションプリセット 6 種 / 好きな画像 (jpg, png, gif, webp) / 動画 (mp4, webm) をライブ壁紙に。暗さ・ぼかし調整つき
- **ウィジェット** (複数追加可)
  - 🕐 時計 — 秒表示 / 12時間 / AM-PM
  - 📅 日付 — 和文・欧文など 6 形式
  - ⛅ 天気 — [Open-Meteo](https://open-meteo.com/) (API キー不要)。都市検索、気温・天気・最高最低
  - ✏️ テキスト — 好きな言葉を表示
  - 📊 システム情報 — CPU / メモリ使用率
- **自由レイアウト**: 「レイアウトを編集」でデスクトップ上を直接ドラッグ。ホイールで文字サイズ、中央・他ウィジェットへスナップ
- **スタイル**: インストール済み全フォント / サイズ / 太さ / 色 / 不透明度 / 字間 / 影 (ソフト・ネオン発光)
- **自動起動**: Windows サインイン時に自動で壁紙を復元 (設定画面は開かない)
- **安定性**: トレイ常駐、レンダラ死活監視、explorer.exe 再起動を検知して自動再アタッチ

## 使い方

1. `WidgetWall-Setup-*.exe` (インストーラ) か `WidgetWall-Portable-*.exe` (単体 exe) を実行
2. 設定画面で壁紙とウィジェットを選ぶ
3. 「🎯 レイアウトを編集」→ デスクトップ上でドラッグして配置 → 保存して完了
4. ウィンドウを閉じてもトレイに常駐して壁紙は表示され続けます (トレイアイコンから再度開けます)
5. 「一般 → Windows 起動時に自動で開始」を ON にすると次回サインインから自動表示

## 開発

```bash
npm install
npm start          # 開発起動
npm run genicon    # アイコン再生成 (assets/)
npm run dist       # exe ビルド (dist/ に NSIS インストーラ + ポータブル exe)
```

## 仕組み

`Progman` に `0x052C` を送って WorkerW を生成させ、Electron のウィンドウを `WS_CHILD` 化して
アイコンレイヤー (`SHELLDLL_DefView`) の背面にある WorkerW へ `SetParent` しています。
Win10 型 (WorkerW が Progman の兄弟) と Win11 24H2 型 (WorkerW が Progman の子) の両レイアウトに対応。
被覆検知 (`CalculateNativeWinOcclusion`) を無効化することで、アイコンの裏でも描画が止まりません。

## 制限

- ウィジェット描画はプライマリモニタのみ (マルチモニタの壁紙スパンは今後対応予定)
- コード署名なしのため、初回実行時に SmartScreen の警告が出ます (「詳細情報」→「実行」)
