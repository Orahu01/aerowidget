# WidgetWall

デスクトップアイコンの**背面**に表示される、ウィジェット付きライブ壁紙アプリ (Windows 10 / 11)。
Wallpaper Engine と同じ WorkerW 方式で、時計・日付・天気・ハードウェアモニタなどを
好きなフォント・サイズ・色・位置で壁紙に直接描画します。

## 機能 (v5)

### 壁紙
- グラデーションプリセット 6 種 + **カスタムビルダー** (最大 10 色・線形/放射/単色、パレット保存)
- 画像 / 動画 (mp4, webm) — 動画は GPU ハードウェアデコード
- **スライドショー** — 複数画像またはフォルダ指定 (追加に自動追従)、シャッフル対応、クロスフェード切替
- **アルバムアート壁紙** — Spotify やブラウザで再生中の曲のジャケットをぼかして壁紙に
- **透過モード「今の壁紙のまま」** — Windows の壁紙はそのままにウィジェットだけ追加
- **オンライン壁紙** — Bing「今日の画像」/ ランダム写真を自動取得 (API キー不要)
- **マウス視差効果** — カーソルに合わせて壁紙がゆっくり動く (オプトイン)
- **壁紙スケジュール** — 昼/夜 または **曜日ごと**に自動切替
- 暗さ・**明るさ**・ぼかし調整、任意の軽量アニメーション
- **マルチモニタ対応** — モニタごとに別の壁紙を設定可能

### テーマとかんたんセットアップ (v5)
- **デスクテーマ集** — 壁紙 + ウィジェット構成の完成品 6 種 (ミニマル / サイバー / 和 / 情報ダッシュボード / フォーカス / ミュージック) をワンクリック適用
- **初回起動ウィザード** — 最初にテーマを選ぶだけで完成。適用前の構成は自動バックアップ
- **設定画面内ライブプレビュー** — デスクトップを見に行かずに配置を確認

### ウィジェット 26 種 (モニタごとに配置可能)
- 時計 (デジタル / アナログ) ・ **世界時計** ・ 日付 ・ カレンダー ・ **カウントダウン**
- 天気 ・ **天気予報 (時間別 / 週間)** (Open-Meteo、API キー不要) ・ テキスト ・ 画像
- **予定表 (ICS)** — Google カレンダーの非公開 URL を貼るだけで今日の予定を表示 (OAuth 不要)
- **ToDo リスト** — デスクトップでチェックできるタスク管理
- **バッテリー** ・ **ディスク空き容量** ・ **ネットワーク情報 (IP / SSID / 遅延グラフ)**
- **ビジュアライザー** — 再生中の音に反応するスペクトラム (再生中のみ描画で省電力を維持)
- **再生中の曲** — 曲名・アーティスト・ジャケット + 再生 / 一時停止・曲送りボタン (SMTC 対応アプリ全般)
- **音量・出力切替** — 音量スライダー、ミュート、再生先デバイス (スピーカー ⇄ ヘッドホン) の切替
- **ニュース (RSS)** — 好きなフィードの見出しを表示・ローテーション
- **株価・為替** — Yahoo Finance ティッカー (日本株 .T / 為替 =X / 暗号資産対応)、前日比を色分け
- **ハードウェアモニタ** — [Libre Hardware Monitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 連携で CPU/GPU 温度・使用率、メモリ、SSD、ネット速度。**推移グラフ**と**温度アラート** (しきい値超えで赤表示)
- **メモ** — デスクトップに直接書き込める付箋 (自動保存)
- **ポモドーロタイマー** — デスクトップ上で開始/停止、セット完了で通知
- **ゾーン** (色分け枠) ・ **ライン** (区切り線) ・ **フォルダ** (アプリまとめランチャー、.lnk/.url 対応)

### カスタマイズ
- 「レイアウトを編集」でデスクトップ上を直接ドラッグ、ホイールでサイズ、ゾーンはハンドルでリサイズ
- **Ctrl+クリックで複数選択 → 整列 / 等間隔配置**、**矢印キーで 1px 微調整**、**Ctrl+Z で取り消し**、**Ctrl+D で複製**、右クリックでロック
- **グローバルホットキー** — ウィジェット表示切替 / アイコン表示切替 / レイアウト切替 / ポモドーロ操作
- デスクトップアイコンの表示 / 非表示 (通常時は設定・トレイから、配置作業中は編集バーから一時切替)
- **英語 UI 対応** (自動判定 / 手動切替)
- フォントは検索できるスクロール式ピッカー (システム全フォント + Google Fonts)
- **Google Fonts をフォント名だけで追加** (ダウンロードしてオフライン使用、日本語フォント対応)
- 太さ / 色 / 不透明度 / 字間 / 影 (ソフト・ネオン発光)
- デジタル時計は桁を固定幅で描画 — 装飾フォントでも秒更新でガタつかない

### 使い勝手・信頼性 (v4)
- **レイアウトプリセット** — 壁紙+ウィジェット配置をまるごと保存し、設定画面やトレイからワンクリック切替
- **設定のエクスポート / インポート** — JSON 1 つでバックアップ・別 PC への移行 (インポート時は自動バックアップ)
- **自動アップデート** — GitHub Releases から新版を自動取得 (インストーラ版。ポータブル版は手動)
- **修復ボタン** — 壁紙が消えた・ずれた時に全ウィンドウを貼り付け直す
- **アンインストール** — 設定画面からワンクリックで起動 (または Windows の「アプリと機能」から)

### デザイン (v3)
- チャコール基調 + ゴールドアクセントのフラットなプロツール風 UI
- 絵文字ではなくストローク SVG アイコン、ヘアライン区切り、タブラー数字

### 省電力設計 (v2 の最重要ポイント)
- 背景は既定で完全静止 — **アイドル時 GPU 使用率 0%**
- 時計は秒表示なしなら**毎分しか起きない**タイマー設計
- **フルスクリーンアプリ検知** (WinEvent フック駆動・ポーリングなし) — ゲーム中はそのモニタの描画を自動停止
- メインプロセスの定期処理は単一ハートビートに集約 (複数 setInterval による CPU 空回りを排除)
- 実測: アプリ全体で 1 コアの約 3% (秒表示時計あり) / GPU 0%

### その他
- 自動起動 (サインイン時に壁紙だけ静かに復元)
- トレイ常駐、explorer.exe 再起動から自動復旧、レンダラ死活監視
- インストーラは最大圧縮 + 不要ロケール除去で軽量化

## 使い方

1. `WidgetWall-Setup-*.exe` (インストーラ) か `WidgetWall-Portable-*.exe` (単体 exe) を実行
2. 設定画面で壁紙とウィジェットを設定
3. 「レイアウトを編集」→ デスクトップ上でドラッグ → 保存して完了
4. ✕ で閉じてもトレイに常駐して壁紙は表示され続けます
5. 「一般 → Windows 起動時に自動で開始」を ON で次回から自動表示

## 仕組み

`Progman` に `0x052C` を送って WorkerW を生成させ、Electron のウィンドウを `WS_CHILD` 化して
アイコンレイヤー (`SHELLDLL_DefView`) の背面にある WorkerW へ `SetParent`。
フォルダウィジェットは逆に Progman 直下の最前面 (アイコンより上・全アプリより下) に置くことで
クリック可能にしています (Rainmeter と同じ層)。
Win10 型と Win11 24H2 型の両ウィンドウレイアウトに対応。DPI スケールが異なるモニタは
物理ピクセルで配置し `zoomFactor` で表示を補正します。

## 制限

- 透過モード「今の壁紙のまま」はスライドショーの切替に追従しません (モニタごとに別の Windows 壁紙を使っている場合は最後に設定した 1 枚になります)
- コード署名なしのため、配布した exe の初回実行時に SmartScreen 警告が出ます (「詳細情報」→「実行」)
